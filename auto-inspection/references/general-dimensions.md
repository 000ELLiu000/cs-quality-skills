# 通用质检维度

## 概述

本层对所有类型的产物执行四个维度的检查，不区分任务类型。每个维度独立判定，不互相影响。

---

## 维度一：准确性

### 检查要点

产出结果是否与事实/标准答案/正确结论相符。

| 检查项 | 说明 |
|--------|------|
| 事实准确性 | 产物内容是否与参考知识库（reference_knowledge）相符，无事实错误 |
| 逻辑自洽 | 产物内部是否存在前后矛盾 |
| 无幻觉 | 是否存在编造不存在的信息（大模型幻觉） |

### 评级标准

- **通过**：无事实错误，逻辑自洽，无幻觉
- **需关注**：存在个别不严谨之处但不影响核心结论（如表述模糊但方向正确）
- **不通过**：存在明确的事实错误、逻辑矛盾，或编造信息

### 降级处理

当 reference_knowledge 未提供时：
- 跳过事实准确性检查（无法对照）
- 仅检查逻辑自洽和无幻觉
- 在 issues 中注明「无参考知识库，仅检查逻辑一致性」

---

## 维度二：遵循性/忠诚度

### 检查要点

结果是否基于给定的背景知识、标注标准、参考 wiki 得出，做到有据可依。

| 检查项 | 说明 |
|--------|------|
| 标准遵循 | 是否严格按照 skill_info 中定义的标注标准/生产规则执行 |
| 有据可依 | 每个判断/标注是否能在输入素材或参考知识中找到依据 |
| 无主观臆断 | 是否存在脱离给定标准的主观判断 |

### 评级标准

- **通过**：严格遵循给定标准，每个结论均有据可依
- **需关注**：个别判断依据不够充分，但整体方向符合标准
- **不通过**：明显偏离给定标准，或存在无依据的主观臆断

### 降级处理

当 skill_info 或 reference_knowledge 未提供时：
- 无法检查标准遵循度
- 在 issues 中注明「无参考标准，遵循性检查降级」

---

## 维度三：完整性

### 检查要点

必填字段/标注项是否都覆盖，无遗漏。

| 检查项 | 说明 |
|--------|------|
| 字段覆盖 | 产物是否包含 skill_info 中定义的所有必填字段/标注项 |
| 内容覆盖 | 产物是否覆盖了 task_goal 中要求的全部内容点 |
| 数据完整 | 是否存在关键信息缺失（字段存在但值为空/无意义） |

### 评级标准

- **通过**：所有必要内容齐全
- **需关注**：非核心内容有缺失（如可选字段为空、辅助信息遗漏）
- **不通过**：核心内容缺失（必填字段为空、task_goal 的关键要求未覆盖）

---

## 维度四：格式合规性

### 检查要点

输出是否符合约定结构/格式规范。

| 检查项 | 说明 |
|--------|------|
| 结构合法性 | 产物是否为合法 JSON / 预期格式 |
| 格式规范 | 字段命名、数据类型、嵌套结构是否符合 skill_info 中定义的格式要求 |
| 值域合规 | 枚举字段的值是否在允许范围内 |

### 评级标准

- **通过**：完全符合格式规范
- **需关注**：格式基本正确但有微小偏差（如多余字段、非关键字段类型偏差）
- **不通过**：格式错误导致下游无法解析（如 JSON 不合法、必填字段类型错误）

---

## 输出格式

每个维度的输出结构：

```json
{
  "status": "通过 | 需关注 | 不通过",
  "pass_rate": "通过率百分比，格式为 'xx%'，如 '94%'",
  "pass_count": "通过的样本数（整数）",
  "total": "该维度检查的样本总数（整数）",
  "issues": [
    {
      "sample_id": "具体样本 ID",
      "description": "问题描述",
      "evidence": "问题内容摘录"
    }
  ]
}
```

- `status` 取该维度下所有样本的最差状态
- `pass_rate` = pass_count / total × 100%，保留整数百分比
- `pass_count` = total - 存在问题的样本数（一个样本在该维度有一个或多个问题都算不通过）
- 无问题时 `issues` 为空数组 `[]`

### 通过率计算规则

- 逐样本判定：对每个样本，检查该维度的所有检查项。只要任一项不满足，该样本在此维度记为"不通过"。
- 汇总计算：`pass_count` = 样本总数 - 不通过样本数，`pass_rate` = pass_count / total × 100%。
- 示例：72 个样本，准确性维度有 4 个样本存在问题 → pass_count = 68，pass_rate = "94%"。
